# SDE Level Notes

A practical collection of notes, roadmaps, and revision material for software-development interview preparation.

## Topics

- Data structures and algorithms
- Object-oriented design and system design
- Databases, operating systems, and computer networks
- Project ideas and interview preparation

## Suggested structure

```text
notes/
  dsa/
  system-design/
  core-cs/
resources/
```

## Getting started

1. Choose a topic and add a focused Markdown note.
2. Include examples, key takeaways, and links to useful references.
3. Review and update the notes as you learn.
